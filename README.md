
# DUHNJN

### About
During my foundation degree experience provided by The University of Cumbria, in 2025, I was influenced by the dungeon crawler Rondure Sorcerer by JasonTaylor to create my own micro-game based on the turn-based combat observed but with pseudo-random variables.

I developed this alone within approximately 3 months using editor version Unity 2022.3.34f1 and I had initially presented this experience to Critical Path’s Robert Clarke in addition to NextGen Skills Academy’s Charlie Blay & Chris Jeffrey.
The sprites along with the C# scripts were once more developed by myself and were excitedly reviewed/play tested by 24+ peers with high praise.

Input was handled utilising the Rewired package made by Guavaman. My short and simple game can be played using **LEFT CLICK** on either the heal and or attack button, whereas **E** on the keyboard is to bring an end to the game without loosing.
Gameplay is endless as once an enemy is defeated, you are rewarded with potions but another enemy will take it’s place.
